# Counting architecture advisor review

On 2026-08-14, three independent subscription-authenticated advisor lanes
reviewed one frozen, sanitized packet: Codex Sol (`gpt-5.6-sol`, xhigh), Claude
Fable, and Gemini 3.1 Pro High. No API-billed inference, video, question,
label, answer, credential, or raw provider log was included.

## Recommendation

All three advisors recommended narrowing—not discarding—the atomic evidence
contract:

`question → frozen CountSpec → route-specific evidence → verification → typed deterministic reducer`

The model should no longer select the count unit, scope, inclusion convention,
or arithmetic. Those policies must be frozen before evidence extraction.
Timestamped atomic records remain useful as inspectable provenance.

The required reducer depends on the question:

- maximum interval concurrency for simultaneous instances;
- onset-in-scope state transitions for repeated actions;
- cut-reset, target-positive shot counting for edited appearances;
- parent/component deduplication under an explicit partial-visibility ontology;
- track deduplication or concurrency for background entities.

Classical tools should be introduced only when a zero-cost diagnostic shows
that they provide a missing primitive, especially shot-boundary proposals.
Maps remain navigation and cannot restrict the global recall sweep.

## Meaningful disagreement

Claude and Sol favored deterministic-first CountSpec compilation with
abstention; Gemini favored a learned text-only compiler. The evidence supports
the conservative synthesis: deterministic rules own explicit unit, boundary,
visibility, and aggregation policy. A learned parser may extract targets or
flag ambiguity, but it must not silently invent counting semantics.

## First bounded action

Before any new paid inference:

1. Freeze a label-blind CountSpec/mechanism manifest for the 26 confirmed
   failures and 12 controls.
2. Implement max-concurrency and onset-in-scope reducers with unit tests.
3. Re-reduce the already-purchased records at zero provider cost.
4. Predeclare that the simultaneity and clip-boundary cases should flip, while
   the background rescue and correct control remain stable. Parts and edited
   shots are not expected to flip without new evidence.

Both predicted flips and zero control regressions would justify requesting a
new held-out paid micro-canary. Zero flips would falsify the specification-only
hypothesis and require completing the mechanism census before further spend.

This review is advice, not a new experiment authorization. It does not change
the valid negative result for the tested generic atomic enumerator.
