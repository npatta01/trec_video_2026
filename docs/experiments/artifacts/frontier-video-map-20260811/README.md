# Gemini native-AV event-map canary artifacts

This tracked bundle is the sanitized evidence projection for the 2026-08-11
two-video frontier event/state-map canary.

- `summary.json` records completion, map structure, validity, and the current
  decision.
- `cost.json` records observed usage and cost.
- `metrics.json` records post-freeze NIST-style semantic metrics and their
  two-row boundary.
- `SHA256SUMS` binds these files.

Competition questions, references, predictions, raw provider responses, video
IDs, media, frames, credentials, and private paths are intentionally excluded.
The private frozen runs, maps, selected frames, contact sheets, and per-row
metrics remain under the canonical ignored data root. Their shared-checkout
locations and audit caveats are recorded in the repository `AGENTS.md`.
