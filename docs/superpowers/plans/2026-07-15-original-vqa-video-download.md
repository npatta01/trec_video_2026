# Original VQA Video Download Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a reproducible `uv`-managed, resumable downloader and launch the original-quality TRECVID VQA YouTube collection as a detached background job.

**Architecture:** A small Python CLI owns manifest generation, `yt-dlp` argument construction, detached process lifecycle, and status reporting. It reads the existing ignored NIST files, writes all runtime state and media beneath ignored `data/vqa/`, and invokes `yt-dlp` through the same `uv` environment without transcoding.

**Tech Stack:** Python 3.12+, uv, yt-dlp, pytest, FFmpeg/ffprobe

## Global Constraints

- Download the best available video stream plus best available audio stream, falling back to the best combined stream.
- Never transcode or downscale video or audio; container merging must use stream copy only.
- Keep media, manifests, logs, PID files, archives, and metadata under ignored `data/vqa/` paths.
- Run training before testing and exclude every ID NIST marks unavailable.
- The job must detach, resume partial downloads, skip archived successes, retry transient failures, and reject duplicate active launches.
- Do not persist credentials or use browser cookies.

```python
import csv
import re
from pathlib import Path

VIDEO_ID = re.compile(r"^[A-Za-z0-9_-]{11}$")


def read_video_ids(csv_path: Path) -> list[str]:
    with csv_path.open(newline="", encoding="utf-8") as handle:
        ids = [row[1].strip() for row in csv.reader(handle) if len(row) >= 2]
    if any(not VIDEO_ID.fullmatch(video_id) for video_id in ids):
        raise ValueError(f"Invalid YouTube ID in {csv_path}")
    return list(dict.fromkeys(ids))


def read_unavailable_ids(readme_path: Path) -> set[str]:
    text = readme_path.read_text(encoding="utf-8")
    names = re.findall(r"(?m)^([A-Za-z0-9_-]{11})\.json\s*$", text)
    quoted = re.findall(r"['\"]([A-Za-z0-9_-]{11})['\"]", text)
    return set(names) | set(quoted)


def write_manifest(csv_path: Path, readme_path: Path, output_path: Path) -> list[str]:
    excluded = read_unavailable_ids(readme_path)
    ids = [video_id for video_id in read_video_ids(csv_path) if video_id not in excluded]
    output_path.parent.mkdir(parents=True, exist_ok=True)
    output_path.write_text("".join(f"https://www.youtube.com/watch?v={video_id}\n" for video_id in ids))
    return ids
```

```python
def build_ytdlp_command(manifest: Path, output_dir: Path, archive: Path) -> list[str]:
    output_dir.mkdir(parents=True, exist_ok=True)
    archive.parent.mkdir(parents=True, exist_ok=True)
    return [
        sys.executable, "-m", "yt_dlp",
        "--batch-file", str(manifest),
        "--format", "bestvideo*+bestaudio/best",
        "--merge-output-format", "mkv",
        "--output", str(output_dir / "%(id)s.%(ext)s"),
        "--write-info-json", "--continue", "--no-overwrites",
        "--download-archive", str(archive),
        "--retries", "10", "--fragment-retries", "10", "--extractor-retries", "3",
        "--ignore-errors", "--no-playlist", "--newline",
    ]
```

`run_downloads` must generate both manifests, call `subprocess.run(..., check=False)` for training and then testing, and return nonzero only when the downloader itself cannot start. Each dataset uses its own archive because the verified training/testing ID overlap is zero.
