## Accessible method summary

The run used the off-the-shelf `Qwen/Qwen3.5-4B` vision-language model. For
each available video, it sampled 12 frames at uniformly spaced bin midpoints.
It did not use audio, transcripts, fine-tuning, test answers, or evaluation
labels.

The normal path used two model calls per question:

1. Generate one concise primary answer from the question and 12 frames.
2. Show the model the same evidence and its primary answer, then request nine
   different alternatives ordered from most to least likely as strict JSON.

If malformed output or normalized duplicates left fewer than ten answers, one
bounded repair call requested only the missing alternatives. If the repair was
still short, deterministic question-type fallbacks filled the remaining
positions. This completion policy belongs only to this archived submission; it
is not the interface for future baseline implementations.

Across the full run, the final 24,430 answer slots contained:

| Source | Answer slots |
|---|---:|
| Primary model answer | 2,443 |
| Ranked-tail model answer | 20,551 |
| Repair-call model answer | 786 |
| Deterministic fallback | 650 |

The organizer `Time` field records measured call wall time. Answers generated
together in a tail or repair call share that call's elapsed time; deterministic
fallbacks have time `0.0`.
