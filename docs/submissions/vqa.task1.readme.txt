Welcome to the TREC2026 VQA Track!
Here you will find the testing dataset for:

1- Answer Generation Task (AG):
   - The folder task1 includes a json file (vqa.2026.testingDataset.Task1.json) that holds all queries for AG task.
   It has the format of
   {
        "Q_ID": 1,
        "Video_ID": "8384.webm",
        "Question": "What happens to the image of the bride and groom?"
    }

    Where Q_ID is the query unique ID
          Video_ID is either a webm video (provided in the zip file "videos.zip") or a YouTube video ID
	  Question: is the question applied to the given video or youtube link and need to be answered by your system
