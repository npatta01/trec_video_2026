# VQA MC V2/V3 direct-video plan

## Objective

Produce two complete, independently auditable Task 2 submissions without
changing V1:

- **V2 targeted hybrid:** retain frozen V1 except on the pre-frozen 818-row
  review queue, where a fresh option-conditioned Gemini native-AV ranking is
  used.
- **V3 full direct video:** use the same fresh option-conditioned Gemini
  native-AV ranking for every media-available row; use the frozen V1 ranking
  only for the ten rows whose testing video is unavailable or for an explicitly
  recorded terminal provider failure.

V4 and V5 are out of scope for this experiment.

## Frozen design

- Model: `gemini-3.7-flash`, native video/audio, 4 FPS, low media resolution,
  high thinking.
- Prompt input: complete video, released question, and all released options.
  It must not contain the Task 1 answer, V1 ranking, audit classification, or
  hidden labels.
- Output: a complete permutation of released numeric option IDs.
- One full direct-video inference freeze supplies both V2 and V3. Running the
  818 V2 requests a second time would duplicate requests already contained in
  V3 without changing the treatment.

## Scientific contract

- **Question:** does direct option-conditioned video inference provide a
  stronger submission candidate than converting the frozen Task 1 answer, and
  is routing only the weak text rows a useful intermediate submission?
- **Control:** frozen V1 text-conversion submission.
- **Treatments:** V2 targeted hybrid and V3 full direct video.
- **Held fixed:** Task 2 rows and order, exact option strings, Gemini model and
  media settings, prompt, seed, and full-ranking parser.
- **Integrity:** predictions freeze before any hidden score; requests exclude
  V1 answers/rankings and audit judgments; submissions may contain only exact
  released option strings.
- **Falsifier:** organizer scoring does not improve on V1, or the run is too
  incomplete to form the declared treatment.
- **Decision rule:** retain all three submissions as distinct candidates; do
  not call V2/V3 better until organizer scoring exists.

## Cost and operational boundary

Google documents Batch API at 50% of standard cost. The current promotional
Gemini 3.7 Flash Batch rates are `$0.375/M` input and `$1.875/M` output through
2026-12-31. The prior matched full native-AV run used 24,712,790 prompt and
1,078,734 output tokens, implying about `$11.29` for this single Batch inference
  freeze at current rates. A deterministic preflight and a hard authorized cap
  must pass before submission. Uploads and provider jobs are private and
  restartable; duplicate batch creation is forbidden. The accepted provider
  job ultimately reported `$12.28247138`, `$0.28247138` above the estimate and
  cap; including the earlier 20-row canary, observed spend was `$12.40184251`.
  No retry was launched.
