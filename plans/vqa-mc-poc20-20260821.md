# TRECVID VQA MC 20-video POC

**Status:** Complete; both families frozen and scored

## Decision

Determine whether two independent model families can return contract-valid,
useful multiple-choice rankings on a small, labeled 2025 panel before scaling
to the full MC release:

- Gemini 3.7 Flash with complete native video/audio;
- Qwen3.6-27B with matched native-video and video-plus-Whisper views;
- equal-family Borda fusion of the Gemini ranking and the within-Qwen fused
  ranking.

This is a contract and catastrophic-failure screen, not a statistically
powered model-selection experiment.

## Frozen design

- 20 unique, locally available videos: four each from temporal, causal,
  OCR/detail, counting, and speech strata.
- Keep the five already inspected deadline-canary videos and add the three
  shortest transcript-available rows in each stratum. Selection uses only
  label-free protocol metadata.
- Shuffle the four answer choices once with a fixed seed and balance the
  correct answer across A/B/C/D. Store correctness in a separate file that
  inference runners cannot accept.
- Main endpoint: top-1 multiple-choice accuracy. Secondary endpoints: mean
  reciprocal rank, strict parse rate, and within-Qwen view agreement.
- Order diagnostic only: reverse displayed option order for the five existing
  canary videos and repeat the canonical order for two of those videos. Do not
  use permutation consensus for the submitted answer.
- Intended initial design: Gemini 27 requests; Qwen 54 requests (27 variants x
  two views). The first Gemini arm exhausted an incorrect 128-token
  high-thinking budget on all 27 calls. Its bounded recovery contains only the
  20 canonical requests; the optional order diagnostic will not be rerun.
- No semantic retries. A malformed response remains a contract failure.

## Predeclared decisions

- Stop and diagnose if either family fails strict ranking parsing on any of
  the 20 canonical rows, or if any run would exceed the combined $2.15 hard
  cap.
- If both families complete and neither shows catastrophic quality, scale the
  same frozen contracts to 475 rows. Do not select a final submission model
  from 20 rows alone.
- Keep provider families equally weighted in the Borda fusion so the two Qwen
  views do not outvote Gemini merely because they are two calls.

## Privacy and persistence

- Questions, options, transcripts, labels, and raw predictions remain under
  ignored `data/vqa/benchmarks/vqa-mc-poc20-20260821/`.
- The successful Qwen run syncs immutable artifacts to a private HF Bucket
  prefix; the tracked report keeps that private locator out of generated pages.
- Only aggregate, sanitized results are recorded in the tracked QMD report.

## Resulting decision

- Keep Gemini native AV as the provisional primary and full-panel control.
- Do not promote Qwen native, Qwen dual-view, or blind equal-family Borda from
  this selected 20-row panel.
- Carry Qwen video plus transcript only as a predeclared speech-route candidate
  for a fresh confirmatory panel.
- Prioritize exact-spelling OCR crops, dense event counting over top-k event-map
  windows, and an evidence-citing top-two verifier; four of Gemini's five misses
  already ranked the correct choice second.
