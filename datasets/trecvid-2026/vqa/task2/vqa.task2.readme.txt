Welcome to the TREC2026 VQA Track!
Here you will find the testing dataset for:

1- Multiple Choice (MC) Task:
   - The folder task2 includes a json file (vqa.2026.testingDataset.Task2.json) that holds all queries for MC task.

   It has the format of
   {
    "Q_ID": 1715,
    "Video_ID": "Liberty_Kid-47.webm",
    "Question": "What does the young man in a black hat do after leaving a convenience store?",
    "Options": [
      {
        "option": "The young man went to play basketball."
      },
      {
        "option": "The young man starts running."
      },
      .
      .
      ]
    }


    Where Q_ID is the query unique ID
          Video_ID is either a webm video (provided in the zip file "videos.zip") or a YouTube video ID
	  Question: is the question applied to the given video or youtube link and need to be answered by your
	  system using the provided answers options.
	  Options: An array of possible answer options to rank them according to their likelihood of being the correct answer.
